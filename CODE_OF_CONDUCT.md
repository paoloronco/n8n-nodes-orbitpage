# Code of Conduct

OrbitPage should be a welcoming, professional place to collaborate on useful
automation software.

## Expected behavior

- Be respectful, constructive, and specific when giving feedback.
- Welcome contributors with different backgrounds and levels of experience.
- Keep discussions focused on the project and its users.
- Respect privacy. Never publish API tokens, workflow credentials, customer
  data, private URLs, or unpatched vulnerability details.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or unwanted attention.
- Deliberate intimidation, disruption, or repeated bad-faith engagement.
- Publishing another person's private information without permission.
- Conduct that would be inappropriate in a professional community.

## Scope and enforcement

This policy applies in repository discussions, issues, pull requests, reviews,
release conversations, and other spaces where someone represents the project.

Report conduct concerns privately to `contact@orbitpage.com`. Maintainers may
remove content and warn, restrict, or ban participants who violate this policy.
Retaliation against a good-faith report is not acceptable.

Security vulnerabilities follow the private process in
[SECURITY.md](./SECURITY.md).
